# 数据库设计

> mdm 主数据管理 · 总纲

[文档首页](../../文档首页.md) › 数据库设计　|　[概要设计 · 总览](../概要设计/01_概要设计_总览.md)

## 1. 文档目的 <a id="purpose"></a>

本文档是 mdm（主数据管理）**数据库设计**的**总纲**：说明数据库设计的组织方式，并登记各主数据域数据表文件、作为入口引用。

- **字段级事实源**＝各表文件（`数据表设计/{表名}.md`）（单表差异）；**通用约定**（公共字段 / 类型映射 / 时间 / 多语言附表 / 索引与唯一约束 / 分片与归档 / 库划分与迁移）与**方言差异**以 **bms《数据库设计》** 为**权威源**（经产品仓库根软链 `bms文档 → ../bms/bms文档` 引用），mdm 侧不复制。
- 表结构变更顺序（强制，见 bms《数据库开发规范》）：**先改表文件（含变更记录）→ 改 ORM 模型 → 生成迁移脚本 → 回写状态**。

> **库名与产品差异**：mdm 库按服务命名（见第 3 节），与 bms 库命名同构；跨库引用一律**逻辑外键**（无跨库物理外键、无跨库 JOIN）。

## 2. 通用约定与方言 <a id="conventions"></a>

以 bms《数据库设计》为权威源（mdm 不复制）：

| 内容 | 权威源（bms） |
| --- | --- |
| 数据规范（公共字段 / 类型映射 / 时间时区 / 多语言附表 / 索引与唯一约束 / 分片与归档 / 库划分与迁移） | bms《数据库设计 · 数据规范》（`bms文档/设计/数据库设计/02_数据库设计_数据规范.md`） |
| 方言特性（MySQL / PostgreSQL / 达梦 DM8 的类型落点 / DDL / 空值语义 / 标识符 / 索引与约束 / 事务与连接） | bms《数据库设计 · 方言特性》（`bms文档/设计/数据库设计/方言特性/`） |
| 建表与迁移口径、字段与性能口径（强制） | bms《数据库开发规范》（`bms文档/规范/数据库开发规范.md`） |

- bms 数据规范已声明：**组织主数据表（`org_dept` / `org_post` / `org_user_post`）与岗位 / 部门分配表（`org_role_post` / `org_role_dept`）随组织主数据外置 mdm，表文件在 mdm 仓库《数据库设计》维护**。
- mdm 表沿用 bms 公共字段（`id` 雪花 / 审计 / 软删除 / `version`）与三库通用逻辑类型；关联表联合主键、不设 `id`。

## 3. 库划分与迁移归属 <a id="libraries"></a>

| 归属库 | 命名 | 迁移链 | 承载 |
| --- | --- | --- | --- |
| mdm 平台库 | `mdm_org` | `org:platform` | 组织域产品级配置（预留，随需要启用） |
| mdm 租户库 | `mdm_org_{code}` | `org:tenant` | 组织主数据（每租户一库；部门 / 岗位 / 关联 / 角色分配） |

- 服务键 `org`、表前缀 `org_`、错误码段 `33xxxx`、事件域 `org.*`（见《[mdm 英文简称规范](../../规范/英文简称规范.md)》与《[mdm 主数据管理规划](../../规划/mdm主数据管理规划.md)》「标识符登记」节）。
- 迁移脚本按服务分链（`alembic/versions/org/{tenant,platform}/`）；SQLite 开发库由启动期按链表集自动建表（口径同 bms）。
