1. 模块概述

岗位管理：岗位归属部门（同库逻辑外键）、岗位码租户内唯一且创建后不可改， 作为主体链中间实体（用户 → 岗位 → 角色）承接角色继承。 对应《概要设计 · 岗位管理》。

2. 界面清单

界面原型（可点击操作）主要交互验证点
岗位管理页岗位管理页.htmlCRUD、归属部门筛选、绑定角色；嵌入主框架时双击行打开岗位表单页
岗位表单页岗位表单页.html表单页分态（只读 / 编辑）、?id=&name= 回填、岗位码编辑态锁定、归属部门树选、保存校验（岗位码 / 名称必填）、删除确认

3. 交互要点

  • 列表：按部门 / 状态 / 关键字筛选，分页；行内「编辑 / 删除」
  • 表单：新建 / 编辑同表单；岗位码创建后锁定（不可改）；归属部门必选且须为启用部门
  • 角色绑定：岗位绑定角色后，其下全部用户获得角色权限（主体链：用户 → 岗位 → 角色）

4. 设计依据

  • 概要：岗位管理
  • 架构：《架构设计 · 权限计算引擎》（主体链）
  • 数据库：org_post、org_user_post、org_role_post
