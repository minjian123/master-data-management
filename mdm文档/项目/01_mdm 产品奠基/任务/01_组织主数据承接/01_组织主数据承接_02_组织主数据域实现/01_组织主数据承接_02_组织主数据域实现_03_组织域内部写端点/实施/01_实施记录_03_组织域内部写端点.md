## 2. 工序与产出 <a id="deliver"></a>

| # | 落点 | 产出 |
| --- | --- | --- |
| 1 | `services/org/src/mdm_org/schemas/internal.py`（新增） | 四组内部请求契约（`InternalUserPostRequest` / `InternalUserDeptRequest` / `InternalRolePostRequest` / `InternalRoleDeptRequest`）；响应**复用公开面** `UserPostIds` / `UserDeptIds` / `RolePostIds` / `RoleDeptIds` |
| 2 | `services/org/src/mdm_org/api/internal.py`（新增） | 四个 `PUT` 内部写端点（`/api/v1/org/internal/{user-posts,user-depts}/{user_id}`、`/internal/{role-posts,role-depts}/{role_id}`）：路由级 `require_service("platform")`；幂等键 `Idempotency-Key`（`begin` / `load` / `save`，载荷回放）；写后推进 `user-roles` 失效代；审计同公开面；用户侧两步（全量覆盖 → 主要项置位 / 清除） |
| 3 | `services/org/src/mdm_org/api/router.py` | 聚合内部写路由（前缀 `/org/internal`，服务级登记表挂 `/api/v1`） |
| 4 | `deploy/contracts/org.json` + `frontend/packages/api-types/src/org.ts` | 契约快照导出与类型重生成（内部路径按拍板**进快照 + 类型**） |
| 5 | `services/org/tests/internal/test_internal_api.py`（新增） | 用例：四端点挂载（均 `PUT`、**无 `GET`**）+ 无令牌 `401`（Kiwi **2274**） |

**口径要点**：内部通道**只换鉴权、不换语义**——复用同一套服务层（校验 / 事务 / 事件 / 失效代 / 审计），不因「内部」绕过任何校验；`org:*` 权限码**不挂**（授权完全由服务身份白名单决定，与只读出口双通道同构）。
