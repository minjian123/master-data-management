## 3. 迁移验证 <a id="migration"></a>

| 项 | 结论 |
| --- | --- |
| 链完整性 | `org:tenant` 链头更新为 `0003_dept_code`（既有写死链头的断言同步） |
| 加列与置非空 | `batch_alter_table` 加列（可空）→ 回填 → `alter_column(nullable=False)`；`code` 无 `server_default` |
| 回填规则 | 按 `id` 升序 `DEPT` + 定长 4 位（超 9999 自动扩位）；仅补空值行（**幂等**）；用例实测 `DEPT0001` / `DEPT0002` |
| 唯一约束 | `uq_org_dept_code_deleted_at`（`code` + `deleted_at`）；软删除行不占用编码（用例覆盖「软删除后复用」） |
| 升到 head 零漂移 | `test_org_tenant_migration_upgrades_with_zero_drift` 通过（库结构 vs 链元数据零差异） |
| 降级往返 | `downgrade` 删唯一约束与 `code` 列；既有降级用例通过 |
| 四库通用 | 未用方言专用类型；真库（MySQL / PG / 达梦）演练随部署窗口（见 §7） |
