## 2. 任务内容 <a id="content"></a>

**口径（2026-11-05 拍板）**：mdm 至今只在开发机跑单测与 CI 静态门禁，**从未以产品形态落到部署主机**——没有运行镜像、没有服务库、没有网关路由、没有前端模块发布。本任务把「代码交付」推到「真实环境可用」，并把部署事实固化为可重复的入口与文档，避免每次靠人肉命令。

> **为什么与 `01_05` 遗留的「部署窗口」合并**：`01_05` 交付注记的遗留项（网关联调、三库真库迁移）与 bms `11_02` 的遗留项（真实网关 / 令牌 / 三库联通）是同一件事的两面，分开执行只会让同一批前置条件准备两次，故合并为一条任务、一套证据。

1. **存量红灯修复（部署前置）**：mdm CI #1544 的 7 个失败收敛为三类根因，逐类修到本地全量绿：
   - **域声明缺失**：bms `37aecef8a`（2026-10-30）起入站先判业务域归属，调用方服务 JWT 须带 `domains` claim；mdm 内部写通道用例的令牌替身补 `domains=("org",)`。
   - **共享测试库跨会话残留**：mdm 的 `addopts` 不加载基座测试插件，会话开始不清 `.cache/test/*.db`；改为 mdm 侧显式 `pytest_sessionstart` 复用基座原语（钉工程根 + DDL 串行化 + 清共享库），用例数据改用命名空间唯一编码。
   - **迁移与模型漂移**：模型已改 `SnowflakeId`，`0001/0002/0004/0005` 仍为 `sa.BigInteger()`；按拍板**直接修订历史迁移**（产品未上线、无生产数据），本地删库重建。
2. **CI 覆盖率口径统一**：`backend-test` 从 `pytest --cov` 改为 `MDM_COVERAGE_DATA` + `engkit coverage`（与本地预检同源），覆盖率正则改读 `percent=`；同时清测试库与 `*.db` 残留。
3. **镜像构建**：mdm CI 新增 `image-build`（`docker:27-cli`，先克隆 bms，上下文取仓库父目录，`--provenance=false`），按 `$CI_COMMIT_SHORT_SHA` 推 GitLab Registry；同时把工作区根 `.dockerignore` 迁为 `mdm/deploy/Dockerfile.dockerignore`（Dockerfile 专用 ignore，CI 与本地共用同一份）。
4. **部署入口**：扩展 bms `release.py`，给 `deploy` / `rollback` / `status` / `health-gate` 增加通用参数（`--compose-file` / `--service` / `--health-path` / `--gateway-path`），不写产品字面量；mdm 侧只提供 compose 与 `.env`，编排实现单点。
5. **服务器首次部署**：保留 `~/bms` 不动，新增 `~/mdm` 检出；建 `mdm` / `mdm_demo` / `mdm_acme` / `mdm_archive` 四库；跑 `ops.migrate`；compose 起 `mdm`；启动期上报平台声明。
6. **网关接入**：`release.py gateway` 按平台注册表重渲 `apisix.yaml`（`route-mdm-mdm` + upstream `mdm`），APISIX 文件轮询热加载；断言 `/api/mdm/v1/mdm/...` 无凭据返回 401。
7. **前端模块发布**：mdm CI `frontend-build` 归档 `frontend/modules/org/dist/`；服务器用 `node:24` 容器（挂载 `~/bms` 与 `~/mdm`）跑 bms `release-module.mjs publish --module mdm_org`，落清单与发布记录。
8. **bms 11_02 真机联合验收**：代码已于 2026-10-08 迁出（bms `e7a0ab092`），本任务补**真实链路证据**（真实网关 / 真实令牌 / 三库），回写 bms `11_02` 测试记录 §5 与本任务测试记录。

## 3. 完成标准 <a id="accept"></a>

① mdm 全量 `pytest` 228 例通过且行 + 分支覆盖率 100%，`ruff` / `ruff format --check` / `pyright` 干净；② mdm CI 手工触发全绿，镜像按 SHA 出现在 Registry 且可启动；③ 服务器 `mdm` 容器健康，`mdm` / `mdm_demo` / `mdm_acme` / `mdm_archive` 四库迁移到 head 且与模型零漂移；④ 平台注册表已收 mdm 声明（产品 / 服务 / 路由 / 能力 / 种子 / 错误码），`/api/mdm/v1/mdm/...` 经网关无凭据返回 401、带有效令牌返回 200；⑤ `mdm_org` 模块产物经四关校验发布，宿主可加载；⑥ bms `11_02` 测试记录 §5 补齐真机证据并回写结论；⑦ 部署入口只由 `release.py` 单点实现，无产品字面量硬编码。
