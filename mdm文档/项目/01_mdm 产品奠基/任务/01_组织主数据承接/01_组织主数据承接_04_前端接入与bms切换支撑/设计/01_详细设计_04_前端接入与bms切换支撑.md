# 01 详细设计 · 前端接入与 bms 切换支撑

> mdm 产品奠基 · 01_组织主数据承接 · 子任务 04（需求 01-4）· 详细设计

## 1. 设计目标与范围 <a id="goal"></a>

承接需求 01-4：mdm **自建前端工程**并以 **Module Federation 运行时模块**接入 bms 宿主，交付组织域管理页（部门 / 岗位）与三个具名插槽插件，生成独立前端类型包；支撑 bms 侧组织选择字段切换 mdm 出口（bms 需求 11-2）并联调验收。

1. **mdm 前端工程**：Vue 3 + TS，与 bms 前端同构（接口封装 / 路由 / 状态 / 页面 / 组件 / i18n / 工具），以运行时模块发布。
2. **组织域管理页**：部门管理、岗位管理（本域 CRUD，经 mdm 组织域契约）。
3. **三个插件**（挂 bms 宿主具名插槽）：用户分配岗位、岗位分配、部门分配。
4. **契约类型包**：`@mdm/api-types`（基于 mdm 组织域 OpenAPI）供 bms 前端消费。
5. **切换支撑**：mdm 保证组织只读出口（01_03）就绪；bms 前端 `OrgSourceAdapter` 改指 mdm 出口（归 bms 11_02）。
6. **联合验收**：配合 bms `org` 服务退役（bms 需求 11-2 / 11-3）验收。

## 3. 前端工程结构 <a id="structure"></a>

```text
mdm/frontend/
├── package.json / pnpm-workspace.yaml
├── src/
│   ├── api/                # 接口封装（经 mdm 组织域契约）
│   ├── views/org/          # 部门管理 / 岗位管理页面
│   ├── modules/org/        # 三个插件（区域项注册）
│   ├── store/ router/ i18n/
│   └── main.ts / module.ts # 应用入口 + 运行时模块暴露
├── packages/api-types/     # @mdm/api-types（契约生成）
└── tests/
```

- **接口基址**：mdm 组织域契约（产品命名空间 `/api/mdm/v1/org/...`），经运行时接入后的宿主 `api` 能力调用（不自建 HTTP 通道）。
- **组件与样式**：复用 bms 设计令牌与组件体系（经宿主注入），不自造重复组件。

## 4. 运行时模块接入 <a id="federation"></a>

- **形态**：mdm 前端以 **Module Federation 运行时模块**发布，由 bms 宿主按模块契约动态加载（框架内动态路由与页签）。
- **模块契约**：暴露路由 / 菜单 / 页面 / 区域项（具名插槽插件），由宿主装配；模块缺失 / 不可达时宿主**不阻塞**、对应入口隐藏（降级）。
- **前端插件化**：遵循 bms《前端开发规范》与《架构设计 · 扩展点与插件化》「前端插件化」「具名插槽」口径。

## 5. 组织域管理页 <a id="views"></a>

| 页面 | 说明 | 契约 |
| --- | --- | --- |
| 部门管理 | 组织架构树、新建 / 编辑 / 移动 / 删除、部门用户 / 角色分配查看 | `/api/mdm/v1/org/depts*` |
| 岗位管理 | 岗位列表（按部门筛选）、新建 / 编辑 / 删除、启停、岗位下用户 / 角色查看 | `/api/mdm/v1/org/posts*` |

- **原型先行（强制）**：界面类开发**开工前须有可交互原型**（`mdm文档/设计/原型设计/`），原型即验收基准（bms《AI开发规范》「界面先原型」红线）；无可交互原型不得进入实施。
- **去实现命名**：原型与页面文案用语义名，不出现实现侧类名 / 能力键 / 文件路径。

## 6. 三个插件（具名插槽） <a id="plugins"></a>

| 插件 | 挂接插槽（bms 宿主） | 写侧 | 权限码 |
| --- | --- | --- | --- |
| 用户分配岗位 | bms 用户管理页 `sys.user.detail.tabs` | mdm `org_user_post`（`/api/mdm/v1/org/user-posts`） | org:update |
| 岗位分配 | bms 角色管理页「角色分配」页签 `sys.role.detail.assign` | mdm `org_role_post`（`/api/mdm/v1/org/role-posts`） | org:update |
| 部门分配 | 同上 `sys.role.detail.assign` | mdm `org_role_dept`（`/api/mdm/v1/org/role-depts`） | org:update |

- **上下文**：宿主页作用实体标识放**路由参数**，插件经注入的 `router` 只读读取；角色表单「角色分配」页签为非路由页面，依赖 bms 基座**显式上下文注入通道**（bms 需求 `05-11`），未就绪前按降级处理。
- **降级**：插件未注册 / mdm 不可达 / 权限不满足 → 该项不渲染，宿主页面其余正常。
- **即时提交**：数据归 mdm，插件写操作即时提交（不随宿主工具栏保存）。

## 7. 契约类型包 <a id="types"></a>

- `@mdm/api-types`：基于 mdm 组织域 OpenAPI 生成（与 bms `@bms/api-types` 生成器同口径），bms 前端按需依赖。
- **零漂移门禁**：生成物与契约快照一致（CI 校验）。

## 8. 与 bms 切换的接口 <a id="switch"></a>

- **mdm 负责**：组织只读出口就绪（01_03）+ 契约稳定（`/api/mdm/v1/org/...`）+ 类型包。
- **bms 负责**（归 bms 需求 11-2）：前端组织选择字段族（`OrgSelectField` / `PostSelectField` / `DeptTreeSelectField` / `OrgCompositePicker`）与 `OrgSourceAdapter` 改指 **mdm 出口基址**（产品命名空间）；`bms_core/org` 契约与装配移除（与 bms 需求 11-2 同步）。
- **联合验收**：前端组织选择经 mdm 出口联通（查询与批量回显分列、部门树一次性返回）；bms `org` 服务退役验收通过。

## 9. 失败分支与边界 <a id="edge"></a>

| 场景 | 处置 |
| --- | --- |
| 插件未注册 / mdm 不可达 | 该 Tab / 区域项隐藏，宿主页面其余正常（不报错、不阻塞） |
| 无 `org:update` 权限 | 插件区域项按权限码判定不渲染 |
| 出口降级（用户来源不可达） | 组织选择字段给出明确降级提示（不静默空） |
| 类型包与契约漂移 | CI 校验失败（阻断） |

## 13. 决策记录 <a id="decision"></a>

| # | 决策项 | 结论 |
| --- | --- | --- |
| 1 | mdm 前端承载形态 | **mdm 自建前端 + Module Federation 运行时模块**接入 bms 宿主 |
| 2 | 组织选择字段切换归属 | **bms 前端改 `OrgSourceAdapter`**（归 bms 11-2）；mdm 保证出口与契约就绪 |
