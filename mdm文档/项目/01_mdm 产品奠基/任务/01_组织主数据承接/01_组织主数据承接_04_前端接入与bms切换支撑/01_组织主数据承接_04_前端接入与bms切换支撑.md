## 2. 任务内容 <a id="content"></a>

**范围（2026-10-08 扩容定稿）**：由「契约类型 + 切换支撑 + 联调」扩容为**含 mdm 前端工程全量**——mdm 自建前端工程并以运行时模块接入 bms 宿主，交付组织域管理页与三个具名插槽插件。

1. **mdm 前端工程与运行时模块接入**：`frontend/` 工作区（Vue 3 + TS + Vite），模块工程以运行时模块形态（模块名 `mdm-org`）独立构建产物；基座包（组件库 / 契约与运行时能力）经工作区内平台仓库引用，不自造重复组件；模块经平台模块清单接入 bms 宿主（发布编排走平台「跨仓接入」口径：平台侧执行发布、链路不持跨仓凭据）。
2. **组织域管理页**：部门管理页（组织架构树 / 新建 / 编辑 / 移动 / 删除）、岗位管理页（按部门筛选列表 / 新建 / 编辑 / 删除 / 启停），均经 mdm 组织域契约；菜单经模块路由声明**自动装配**、文案经模块多语言包。
3. **三个具名插槽插件**：用户分配岗位（bms 用户管理页页签）、岗位分配与部门分配（bms 角色管理页「角色分配」页签）；写侧归 mdm（`org:update`），分配即时提交；上下文只读取用（路由参数 / 宿主显式上下文），缺失即降级不请求。
4. **契约类型包**：mdm 自持类型生成管道（自 mdm 组织域公开契约快照生成），生成物与契约快照**零漂移**并入门禁。
5. **切换支撑与联调**：mdm 侧交付类型包、契约对齐与联调方案；与 bms `11_02` 联合验证前端组织选择经 mdm 出口联通（查询与批量回显分列、部门树一次性返回）。

## 3. 完成标准 <a id="accept"></a>

① 前端工程可独立构建出**可接入平台的模块产物**（容器入口 + 产物元数据 + sourcemap），管理页与三个插件经**可交互原型逐页对照**通过；② 类型生成物与契约快照**零漂移**（门禁可复跑）；③ 前端组织选择经 mdm 出口联通（查询与批量回显分列、部门树一次性返回）——与 bms `11_02` 联合验收；④ 前端工程门禁全绿（lint / 类型检查 / 用例 / 构建与体积预算）；⑤ bms `org` 服务退役验收通过（bms 需求 `11-2` / `11-3`）。
