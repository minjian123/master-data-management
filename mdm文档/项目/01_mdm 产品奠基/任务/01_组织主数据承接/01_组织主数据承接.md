# 组织主数据承接

> mdm 主数据管理 · 阶段一（mdm 产品奠基） · 需求域01：组织主数据承接（4 条任务）

[文档首页](../../../../文档首页.md) › [阶段一（mdm 产品奠基）需求总览](../../需求/00_需求_mdm产品奠基.md) › 组织主数据承接　|　[任务清单见下表](#list)

## 1. 域说明 <a id="intro"></a>

本域对应 mdm 阶段一「组织主数据承接」：mdm 落产品工程骨架与平台接入，实现组织主数据域（部门 / 岗位 / 用户-岗位 / 岗位与部门角色分配），交付组织只读出口两契约（组织数据源 / 名称回显）与用户-岗位契约、按用户解析角色只读契约，并配合 bms `org` 服务退役与前端组织选择字段切换。依据《[mdm 主数据管理规划](../../../../规划/mdm主数据管理规划.md)》「组织服务归位」「标识符登记」节与《[架构设计 · 总览](../../../../设计/架构设计/01_架构设计_总览.md)》「域服务划分与数据边界」节；对应需求域一（01-1 ~ 01-4）。

**依赖与顺序**：本域为 bms 侧「组织服务退役」（bms 阶段二 需求域十一）**前置**——mdm 先实现、bms 后退役；`01_03` 交付后方可 `01_04` 与 bms 退役。

## 3. 依赖与风险 <a id="dep"></a>

- **关键依赖**：`01_02` 依赖 `01_01`；`01_03` 依赖 `01_02`；`01_04` 与 bms 侧退役依赖 `01_03`（见各子任务「任务信息」表「依赖」行）。
- **风险**：mdm 无代码，属**产品从零奠基**，工程骨架、平台接入与 CI/部署均需新建，投入面大；以「平台复用（不重复认证 / 权限 / 审计 / 事件）+ 组织域单域先落」控制范围（详见[计划文档](../../计划/01_计划_mdm产品奠基.md)「风险与对策」节）。
