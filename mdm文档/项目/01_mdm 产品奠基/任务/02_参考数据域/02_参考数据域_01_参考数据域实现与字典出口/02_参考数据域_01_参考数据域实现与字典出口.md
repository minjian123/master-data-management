## 2. 任务内容 <a id="content"></a>

**口径来源（2026-10-11 用户拍板）**：**字典＝基础数据 / 参考数据**（含主数据但不止主数据）；bms `02_09` 已剔除编造的「字典类型 / 条目 / 属性」，字典数据由各所有者域承载；**纯参考类字典（region 等）落 mdm 数据实体**。**bms `02_10` 提供统一的通用数据出口基类与实现类**（字典系统字段统一，可通用 / 继承），**各项目直接使用或继承**——mdm 不重复实现取数 / 缓存 / 翻译 / 版本比对。

1. **数据模型**：纯参考类字典实体——行政区划 `region`（省 / 市 / 区级联，`parent_id` 自引用）为首个实体；另含计量单位 / 币种汇率 / 结算方式 / 税率等。先表文件（含变更记录）→ ORM 模型 → 迁移（`{域}:tenant` 链）。系统字段按《数据库开发规范》§3.1.3 字典（`form_key` + `code` / `name` / `status` / `parent_id`）——实体表落 **`form_key`**；`data_source_key` **不落实体表**（归 bms 数据源注册）。
2. **通用出口接入**：**直接使用或继承 bms 通用数据出口基类 / 实现类**（读标准字典系统字段 `code` / `name` / `parent_id` / `sort` / `status`）；按 `data_source_key`（如 `region`）登记为**字典数据源**，供 bms 字典出口（`/api/v1/dicts/{data_source_key}` 路由）/ 前端经网关直取（产品命名空间 `/api/mdm/v1/{域}/...`）。
3. **维护能力**：各实体 CRUD + 录入校验 + 唯一约束 + 审计（复用平台能力）；参考数据亦可以幂等种子下发。
4. **标识符登记**：参考数据域标识符（域简称 / 表前缀 / 业务码 / 错误码段 / 事件域）按登记制确定，回写《[mdm 主数据管理规划](../../../../../规划/mdm主数据管理规划.md)》「标识符登记」节与平台服务目录；与 mdm 规划**预留域**（`uom` / `cur` / `settle` / `rate`）的对齐 / 合并关系于详细设计确定。

> 详细设计（含数据表设计、出口契约、跨仓对接与测试映射）随后续开发窗口另出——本任务**仅立项**。

## 3. 完成标准 <a id="accept"></a>

- □ 参考数据实体落库，迁移可跑（表文件 ↔ 模型 ↔ 迁移零漂移）
- □ 实体表系统字段对齐规范（落 `form_key`，《数据库开发规范》§3.1.3 字典 5 项）
- □ 经 **mdm 通用出口**按 `data_source_key` 真实取数（继承 / 使用 bms 通用数据出口）
- □ bms 字典出口（`data_source_key` 路由）/ 前端经网关直取可读（跨仓联通）
- □ 标识符登记齐备（mdm 规划 + 平台服务目录）
- □ `pytest` / `ruff` / `pyright` 全绿；定向用例通过
