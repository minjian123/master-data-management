# 参考数据域

## 1. 域说明 <a id="intro"></a>

本域对应 mdm 阶段一「参考数据域」：落**纯参考类字典**（行政区划 `region` + 计量单位 / 币种汇率 / 结算方式 / 税率等）的**数据实体**，并经 **bms 统一通用数据出口**（各项目直接使用或继承；字典系统字段统一故可通用 / 继承）供 bms 字典出口（`dict_key` 路由）与前端消费。依据《[mdm 主数据管理规划](../../../../规划/mdm主数据管理规划.md)》「主数据域」「标识符登记」节与 bms 阶段一任务 `02_09`（字典数据源登记 + 统一出口）；对应需求域二（02-1）。

**依赖与顺序**：本域依赖 **bms `02_09` 补强**（通用数据出口基类 + 可直用 / 可继承实现类）；bms 补强就绪后方可实施本域。

## 3. 依赖与风险 <a id="dep"></a>

- **关键依赖**：本域依赖 bms `02_09` 补强（通用数据出口基类 / 实现类）——跨仓前置，随 bms 该补强交付后推进。
- **风险**：参考数据域标识符（表前缀 / 业务码 / 错误码段 / 事件域）与 mdm 规划**预留域**（`uom` / `cur` / `settle` / `rate`）的合并 / 对齐关系未定——归详细设计确定并回写规划与平台服务目录；跨仓出口对接（bms 通用出口 ⇄ mdm 数据实体）须以「系统字段统一」为约束，避免字段口径发散。
