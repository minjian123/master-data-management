## 1. 文档说明 <a id="purpose"></a>

本文档集是 **mdm（主数据管理）产品阶段一（mdm 产品奠基）** 的需求基线：mdm 目前仅有文档、尚无代码，**首个阶段以「组织主数据承接」为切入**——配合 bms 原 `org` 服务退役，把**组织主数据（部门 / 岗位 / 用户-岗位 / 岗位与部门角色分配）**落到 mdm 产品，并交付**组织只读出口**（组织数据源 / 名称回显）与**用户-岗位契约**、**按用户解析角色只读契约**，供 bms 与业务产品一致性引用。按需求域拆分：

| 文档 | 内容 |
| --- | --- |
| 本文档 `00_需求_mdm产品奠基` | 阶段一目标、范围、需求总清单、需求域文档地图 |
| [01_需求_组织主数据承接](01_需求_组织主数据承接.md) | mdm 产品工程骨架与平台接入 / 组织主数据域实现 / 组织只读出口与用户-岗位契约 / 前端接入与 bms 切换支撑 / 组织主数据表系统字段对齐 / mdm 服务标识归并（6 条） |
| [02_需求_参考数据域](02_需求_参考数据域.md) | 参考数据域实现与字典出口（纯参考类字典：行政区划 `region` + 计量单位 / 币种汇率 / 结算方式 / 税率；经 bms 通用数据出口）（1 条） |

- **进度与验收**：需求文档只写「做什么与验收标准」；进度与验收门禁、证据归阶段计划文档（需求文档不承载进度）。
- **依据**：《[mdm 主数据管理规划](../../../规划/mdm主数据管理规划.md)》（产品定位、主数据域全景、平台复用边界、组织服务归位、标识符登记）、《[mdm 知识档案总览](../../../资料/知识档案/mdm知识档案总览.md)》主数据管理专题（15 篇）、bms《微服务演进规划》《平台可扩展性规划》《架构设计》（经产品仓库根软链 `bms文档 → ../bms/bms文档` 引用）、《[需求文档规范](../../../../bms文档/规范/需求文档规范.md)》。
- **依赖**：本阶段为 bms 侧「组织服务退役」（bms 阶段二 需求域十一）**前置**——mdm 需求 `01-3`（组织只读出口就绪）交付后，bms 方可退役并切契约。

## 2. 阶段一目标与范围 <a id="goal"></a>

**阶段目标**（《[mdm 主数据管理规划](../../../规划/mdm主数据管理规划.md)》「演进路线与验收判据」节阶段一 / 二）：mdm 产品**工程骨架与平台接入落地**，**组织主数据域实现**并对外提供**组织只读出口与用户-岗位契约**，支撑 bms `org` 服务退役与业务产品（biz 等）对组织的引用。

**范围内**（共 7 条需求，见第 3 节总清单）：

| 需求域 | 内容 |
| --- | --- |
| 01 组织主数据承接 | mdm 产品工程骨架与平台接入、组织主数据域实现（部门 / 岗位 / 用户-岗位 / 岗位与部门角色分配）、组织只读出口与用户-岗位契约（含契约自 `bms_core/org` 迁入）、前端接入与 bms 切换支撑、组织主数据表系统字段对齐（`form_key` / `parent_id`）、mdm 服务标识归并（`org` → `mdm` + 产品登记装载时注册） |
| 02 参考数据域 | 纯参考类字典（行政区划 `region` + 计量单位 / 币种汇率 / 结算方式 / 税率）**数据实体**，经 **bms 通用数据出口**（直接使用 / 继承）供 bms 字典出口与前端消费 |

**范围外**：

- 供应商 / 客户 / 物料等其余主数据域——随业务产品需要分批接入（登记见《[mdm 主数据管理规划](../../../规划/mdm主数据管理规划.md)》「主数据域全景」节）。
- 用户 / 角色 / 菜单 / 权限 / 系统参数等**平台运行必需基础数据**——归 bms 基座，不入 mdm；**参考数据类字典**（行政区划等纯参考值）按「数据本体归所有者域」口径入 mdm（见需求域二）。
- 数据管家 / 审批流 / 质量稽核看板等完整治理能力——按《[mdm 主数据管理规划](../../../规划/mdm主数据管理规划.md)》「数据治理与质量」节随域演进（组织域首批先落录入校验与唯一约束）。
