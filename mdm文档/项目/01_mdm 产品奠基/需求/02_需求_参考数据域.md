## 1. 域说明 <a id="intro"></a>

本域对应 mdm 阶段一「参考数据域」：**纯参考类字典**（行政区划 `region` + 计量单位 `uom` / 币种汇率 `cur` / 结算方式 `settle` / 税率 `rate` 等）由 mdm 承载**数据实体**，并经 **bms 统一通用数据出口**（各项目**直接使用或继承**；字典**系统字段统一**——`code` / `name` / `parent_id` / `sort` / `status` 等，故可通用 / 继承）供 bms 字典出口（`data_source_key` 路由）与前端消费。

> **口径来源（2026-10-11 用户拍板）**：bms 侧 `02_09` 已剔除 AI 自行编造的「字典类型 / 字典条目 / 字典属性」一套，字典数据改由各所有者域承载；**「字典」＝基础数据 / 参考数据**（含主数据但不止主数据）。**纯参考类字典（region 等）归 mdm 承载数据实体**，经 bms 通用数据出口供数——**mdm 侧只落数据实体与出口接入，不重复实现取数 / 缓存 / 翻译**。

**依据**：《[mdm 主数据管理规划](../../../规划/mdm主数据管理规划.md)》（「主数据域」「标识符登记」节）、《[mdm 英文简称规范](../../../规范/英文简称规范.md)》、bms《命名规范》《英文简称规范》（经软链 `bms文档` 引用）、bms 阶段一任务 `02_09`（字典数据源登记 + 统一出口）、`02_10`（统一数据源注册与通用数据接口）。

**依赖与顺序**：本域依赖 **bms `02_10`（统一数据源注册与通用数据接口）**（在已交付 `BaseDictDataProvider` 抽象基类 + `RoutedDictSource` 出口基础上，补**可直用 / 可继承的通用数据出口实现类**——读标准字典系统字段表）；bms `02_10` 就绪后 mdm 方可落数据实体并接入出口。

## 2. 需求 02-1：参考数据域实现与字典出口 <a id="r02-1"></a>

优先级：2（高）

**背景与动机**：bms `02_09` 拆除平台侧字典表后，纯参考类字典（行政区划等）无平台侧承载；按「字典＝基础数据 / 参考数据、数据本体归各所有者域」口径，须由 mdm 承载其**数据实体**并经**统一出口**供数。因字典系统字段统一，出口应经 **bms 通用数据出口**（直接使用或继承）实现，**零重复实现**取数 / 缓存 / 翻译 / 版本比对。

**内容**（《[mdm 主数据管理规划](../../../规划/mdm主数据管理规划.md)》「主数据域」节；bms 阶段一任务 `02_09` 详设「字典数据源登记 + 统一出口」节、`02_10`（统一数据源注册与通用数据接口））：

1. **数据模型**：纯参考类字典实体——行政区划 `region`（省 / 市 / 区级联，`parent_id` 自引用）为首个实体，另含计量单位 / 币种汇率 / 结算方式 / 税率等（按域登记表前缀与系统字段）；先表文件（含变更记录）→ ORM 模型 → 迁移。
2. **通用出口接入**：**直接使用或继承 bms 通用数据出口基类 / 实现类**（读标准字典系统字段）；按 `data_source_key`（如 `region`）登记为**字典数据源**，供 bms 字典出口（`data_source_key` 路由）与前端经网关直取。
3. **维护能力**：各实体 CRUD + 录入校验 + 唯一约束 + 审计（复用平台能力），或按参考数据特性只读种子。
4. **标识符登记**：参考数据域标识符（域简称 / 表前缀 / 业务码 / 错误码段 / 事件域）按登记制确定并回写 mdm《主数据管理规划》与平台服务目录；与 mdm 规划已**预留**的 `uom` / `cur` / `settle` / `rate` 域的对齐 / 合并关系于详细设计确定。

**完成标准**：数据实体落库且迁移可跑；经 mdm 通用出口按 `data_source_key` 真实取数（bms 字典出口 / 前端直取可读）；`pytest` / `ruff` / `pyright` 全绿。

**参考文档**：《[mdm 主数据管理规划](../../../规划/mdm主数据管理规划.md)》「主数据域」「标识符登记」节；《[mdm 英文简称规范](../../../规范/英文简称规范.md)》；bms 阶段一任务 `02_09`（字典数据源登记 + 统一出口）与其详细设计、`02_10`（统一数据源注册与通用数据接口）
