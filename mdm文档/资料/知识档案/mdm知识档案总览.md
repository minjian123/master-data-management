## 1. 用途与阅读建议 <a id="purpose"></a>

本目录是 mdm（主数据管理）产品的**知识档案**（辅助参考）：沉淀与主数据管理相关的**行业标准做法、概念体系与取舍**，供规划、设计与实施时查阅。

- 定位为**理解用参考资料**，会过时、不具强制力；**本项目的强制口径只认 `规范/` 下的规范与 `规划/`、`设计/` 文档**（规划 → 设计 → 详细设计）。
- 每篇相互独立，可按需单独阅读；建议先读专题《[01 总览](主数据管理/01_主数据管理_总览.md)》。
- 涉及平台机制（认证 / 权限 / 事件 / 审计 / 微服务等）的通用知识，权威源在 bms 仓库知识档案（经产品仓库根软链 `bms文档 → ../bms/bms文档` 引用），本目录不复制。
- 每篇末尾带「参考文献」（外部网址）与「项目内关联文档」（内部相对路径链接）。

## 4. 与本项目的关系 <a id="relation"></a>

- 本目录是**知识档案**，回答「主数据管理有哪些标准做法、各有什么取舍」；本项目**产品定位、主数据域边界、平台接入与标识符登记**以《[mdm 主数据管理规划](../../规划/mdm主数据管理规划.md)》为准，**实现细节**以《[设计](../../设计/概要设计/01_概要设计_总览.md)》与详细设计为准。
- 通用基础数据（用户 / 角色 / 菜单 / 权限 / 字典 / 系统参数）归 BMS 平台，不在 mdm 知识档案范围；平台机制知识见 bms 仓库知识档案《技术栈知识档案总览》。
