## 1. 用途说明 <a id="purpose"></a>

本文档是 `mdm文档/` 目录的**全量索引**，汇总 mdm 项目全部规划、规范与设计文档，按目录分类提供跳转入口。mdm 为 BMS 平台之上的**产品服务（独立服务）**产品，专门承载**部门、岗位、供应商、客户、物料**等**跨业务项目公用基础数据**（主数据）：**用户 / 角色 / 菜单 / 权限 / 字典 / 系统参数**等平台运行必需基础数据仍属 bms 基座，不在本仓库。**通用规范与共享资料为统一基座，权威源在 bms 仓库，本仓库以产品仓库根软链 `bms文档 → ../bms/bms文档` 并排引用**；本仓库只放产品专属内容（规划、主数据设计、专属规范）。文件格式约定：正文载体不限（`.md` / `.html`），线框图/可交互原型用 `.html` 资产（见《[文档生成规范](../bms文档/规范/文档生成规范.md)》）。

## 2. 目录结构总览 <a id="structure"></a>

```text
mdm文档/
├── 规划/       # 项目级规划文档（产品专属）
├── 规范/       # 产品专属规范（mdm《英文简称规范》等；通用规范基座 bms）
├── 项目/       # 按阶段的项目基线（需求 / 任务 / 计划）
├── 设计/       # 主数据体系设计（总纲 + 节点，随开发阶段填充）
│   ├── 架构设计/ # 主数据外置与平台接入架构
│   ├── 概要设计/ # 组织/供应商/客户/物料主数据模块设计
│   ├── 数据库设计/ # 主数据表字段级设计（组织域 5 表）
│   └── 原型设计/ # 可交互界面原型（组织域：岗位管理 / 部门管理）
├── 资料/       # 产品专属资料与知识档案（主数据管理专题等）
│   └── 知识档案/ # 知识档案总览 + 主数据管理专题（15 篇）
└── 用户文档/   # 本地资源（机器凭据等，已 gitignore）
（基座经产品仓库根软链 `bms文档 → ../bms/bms文档` 并排引用，路径前缀 `../bms文档/`）
```

| 文件夹 | 用途 | 典型文档 |
| --- | --- | --- |
| `规划/` | 产品顶层规划：定位、主数据域全景、平台复用边界、标识符登记、演进路线 | 《mdm 主数据管理规划》 |
| `规范/` | 产品专属规范（通用规范为基座 bms，本目录只放产品专属） | 《英文简称规范（mdm）》 |
| `项目/` | 按阶段的项目基线：需求 / 任务 / 计划 | 随开发阶段填充 |
| `设计/` | 主数据体系设计：架构设计（平台接入）、概要设计（主数据模块）、原型设计（可交互界面） | 《概要设计 · 总览》《岗位管理》《部门管理》《供应商》 |
| 基座（规范/资料/资源） | 由产品仓库根软链 `bms文档 → ../bms/bms文档` 并排提供（权威源 bms，引用路径 `../bms文档/…`）；本仓库只放产品专属内容 | 《文档生成规范》《命名规范》《开发服务器部署使用说明总览》等 |

> 浏览建议：先读「规划」（本产品定位与主数据域边界），机制不明时查 bms《微服务演进规划》《平台可扩展性规划》《项目规划说明》，开发时遵循「规范」（基座）。用户 / 角色 / 权限等平台基础数据见 bms 概要设计，不在本仓库。
